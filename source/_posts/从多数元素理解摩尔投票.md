`题目：给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。`
`你可以假设数组是非空的，并且给定的数组总是存在多数元素。`
`示例 1：`
`输入：nums = [3,2,3]`
`输出：3`

<!-- more -->

## **法一：**

哈希表统计法： 遍历数组 nums ，用 HashMap 统计各数字的数量，即可找出 众数 。此方法时间和空间复杂度均为 O(N) 。

## **法二：**

摩尔投票法： 核心理念为 票数正负抵消 。此方法时间和空间复杂度分别为 O(N) 和 O(1) ，为本题的最佳解法。

**摩尔投票：**

设输入数组 nums 的众数为 x ，数组长度为 n。则有两个推论：

推论一：若记 众数 的票数为 +1 ，非众数 的票数为 −1 ，则一定有所有数字的 票数和 >0 。

推论二：若数组的前 a 个数字的 票数和 =0 ，则 数组剩余 (n−a) 个数字的 票数和一定仍 >0 ，即后 (n−a) 个数字的 众数仍为 x

因此可得，在遍历时记数组首个元素为n，众数为x，开始统计票数。当票数和=0时，重新让x等于当前元素，这样最后众数一定会等于x。原因：由推论二得当票数为0时后面的众数不变，因此：

1.若后面的众数都比较靠前：则votes会始终大于0，不会出现重新赋值众数的情况。

2.若后面的众数有一些比较靠后：那么重新赋值后只能是在x等于众数时才会走到最后，因为众数是最多的。

**源码：**

```
class Solution {    
	public int majorityElement(int[] nums) {
    int x = 0, votes = 0;
    for (int num : nums){
    	if (votes == 0) x = num;
    	votes += num == x ? 1 : -1; 
    } 
    return x;    
    }
 } 
```

**时间复杂度 O(N) ： N 为数组 nums 长度。
空间复杂度 O(1) ： votes 变量使用常数大小的额外空间。**

**拓展：**
由于题目说明“给定的数组总是存在多数元素”，因此本题不用考虑 数组不存在众数 的情况。若考虑，需要加入一个 “验证环节” ，遍历数组 nums 统计 x 的数量。

若 x 的数量超过数组长度一半，则返回 x 。否则，返回未找到众数。

```
class Solution {
    public int majorityElement(int[] nums) {
        int x = 0, votes = 0, count = 0;
        for (int num : nums){
            if (votes == 0) x = num;
            votes += num == x ? 1 : -1;
        }
        // 验证 x 是否为众数
        for (int num : nums)
            if (num == x) count++;
        return count > nums.length / 2 ? x : 0; // 当无众数时返回 0
    }
}
```
