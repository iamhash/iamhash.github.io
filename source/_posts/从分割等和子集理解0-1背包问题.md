## 背景

`题目：给你一个 只包含正整数 的 非空 数组 nums 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。`

<!-- more -->

`示例 1：`

`输入：nums = [1,5,11,5]`
`输出：true`
`解释：数组可以分割成 [1, 5, 5] 和 [11] 。`
`示例 2：`

`输入：nums = [1,2,3,5]`
`输出：false`
`解释：数组不能分割成两个元素和相等的子集.`

## 思路

本题是经典的01背包问题。本题的目标是找到一个子集，使得它的和等于数组总和的一半。设总和为sum，若为奇数一定不能分。问题就变成了：**从数组中选择一些元素（每个最多选一次），使得它们的和正好为 sum / 2。**

01背包经典定义：有一个容量为 target 的背包（这里就是 sum / 2），有 n 个物品（每个物品只能选一次），每个物品的重量是 nums[i]，没有价值，只看是否能恰好装满背包。

01 背包问题本质：有一个「容量为 W 的背包」，有 n 个「物品」，每个物品有「重量」和「价值」，每个物品只能选择一次。

求：在不超过背包容量的前提下，能获得的最大价值。

【从一组元素中选择若干个（每个最多选一次），在满足某种约束（例如总容量/总和/个数等）下，使得某种目标（例如总价值/是否存在）最大化或可达。】

## **动态规划解法：**

状态定义：dp[j]：表示容量为 j 的背包，是否可以被填满。【类型为boolean；初始值dp[0]=true（容量若为0 则什么都不装即可）

状态转移方程：外层循环遍历数组的每个数字，内层循环对于每个数字num从后向前枚举容量j至当前元素【因为若容量若小于当前元素 则一定用不上当前元素，因此就没有更新的必要】每个容量j更新的方程为：dp[j]=dp[j] || dp[j-num]；

### **为什么内层循环要从后向前遍历？**

**防止重复使用一个物品。这是 0-1 背包的经典技巧。**

举个例子：假设：nums = [1, 5, 11, 5]，target = 11。

当我们使用下面这段代码（从前向后）处理时：

```
for (int num : nums) {
for (int j = num; j <=target ; j++) {
dp[j] = dp[j] || dp[j - num];
}
}
```

当遍历到当前元素为5，会先发生dp[5]=true,此时5已经用了一次了，当处理到dp[10]时，会发现又能变为true，但此时会发生数字5使用了两次。而若从前向后遍历，那么当处理到dp[10]时dp[5]还未更新，因此dp[10]不会更新为true，这也符合了逻辑。

因此本题使用boolean类型的dp数组，最后判断dp[target]是否为true即可。

代码：

```
class Solution {
    public boolean canPartition(int[] nums) {
        int sum=0;
        for(int num:nums){
            sum+=num;
        }
        if(sum%2!=0)return false;
        int target=sum/2;
        boolean[] dp=new boolean[target+1];
        Arrays.fill(dp,false);
        dp[0]=true;
        for(int num:nums){
            for(int j=target;j>=num;j--){
                dp[j]=dp[j] || dp[j-num];
            }
        }
        return dp[target];
    }
}
```
