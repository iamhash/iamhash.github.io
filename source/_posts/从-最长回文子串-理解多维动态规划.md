`给你一个字符串 s，找到 s 中最长的 回文 子串。`
`示例 1：`
`输入：s = "babad"`
`输出："bab"`
`解释："aba" 同样是符合题意的答案。`
`示例 2：`
`输入：s = "cbbd"`
`输出："bb"`
<!-- more -->

## 核心：

看到本题时很难想到用二维动态规划数组来解题，但对于这种需要在循环中判断是否回文之类的会想到用boolean类型数组`类似的还有分割等和子集、单词拆分`。而本题所用的dp[i][j]是代表在字符串s中的第i到j个位置的子字符串是否为回文串。

## 切入点:

本题的一个切入点是在每层循环中首先判断当前第i个位置和第j个位置元素是否相等（从而来判断回文串），若不相等则说明一定不为回文串；若相等时，分三种情况：
1.下标i与j相同，为同一个字符串，一定回文。
2.下标i与j相差1，例如aa，也是回文子串。
3.下标i与j相差大于1时，则需要继续判断dp[i+1] [j-1]是否为true。 

## 初始化：

本题刚开始一定不会匹配，因此dp所有元素初始化为false。注意：这里因为时二维数组，因此不能直接使用：Arrays.fill(dp,false);会报错。对于二维数组的填充，可在一层for循环中使用上述式子，即：

```
for(int i=0;ii<s.length();i++){

Arrays.fill(dp[i],false);

}
```



## 遍历顺序：

由上述情况三可知，当遍历dp[i] [j]时必须知道dp[i+1] [j-1]的状态，而dp[i+1] [j-1]在dp[i] [j]的左下方。因此必须要将i倒序遍历，首先判断左和下。（可以想象成一个表格，左下角元素必须要先遍历，然后再遍历当前元素。）

##  源码：

```
class Solution {
    public String longestPalindrome(String s) {
        if(s.length()==0||s==null)return s;
        boolean[][] dp=new boolean[s.length()][s.length()];
        char[] chars=s.toCharArray();
        int maxLen=0;
        int left=0;
        int right=0;
        for(int i=0;i<s.length();i++){
            Arrays.fill(dp[i],false);
        }
        for(int i=s.length()-1;i>=0;i--){
            for(int j=i;j<s.length();j++){
                if(chars[i]==chars[j]){
                    if(j-i<=1){
                    dp[i][j]=true;
                    }else{
                        if(dp[i+1][j-1]){
                            dp[i][j]=true;
                        }
                    }
                }
                if(dp[i][j]&&(j-i+1)>maxLen){
                    maxLen=j-i+1;
                    left=i;
                    right=j;
                }
            }
        }
        return s.substring(left,right+1);
    }
}
```
